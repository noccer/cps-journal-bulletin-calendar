Le Journal Calendar
School dates from Le Journal and Le Bulletin

For CPS parents

Add school dates to the calendar you already use

This parent-made calendar adds important dates from the official school calendar, Le Journal, and Le Bulletin to your calendar application.

Add it using the steps below. If your app gives you a choice, use the subscription link and do not download the file, or it will stop updating. If you want the full official school calendar as well, you can open that separately.

Add it to your calendar

Pick the calendar app you use most, then follow the short steps.

New dates may take a few hours to appear. Most calendar apps do not update straight away.

Apple Calendar

Best for iPhone, iPad, and Mac users.

1. Copy this subscription link.

If copy does not complete, the link will stay selected so you can copy it manually.

2. Open Apple Calendar.

3. Start a new subscription calendar. On Mac use File > New Calendar Subscription. On iPhone or iPad use Calendars > Add Calendar > Add Subscription Calendar.

4. Paste the link and finish adding it.

Google Calendar

Easiest to set up in a computer browser first. It will then show on your phone as well.

1. Copy this subscription link.

If copy does not complete, the link will stay selected so you can copy it manually.

2. Open Google Calendar's From URL page in a web browser.

Open From URL page

3. Paste the link into the box and add the calendar.

4. Open the Google Calendar app later if you want to see it on your phone.

Outlook

Best added from Outlook on the web.

1. Copy this subscription link.

If copy does not complete, the link will stay selected so you can copy it manually.

2. Open Outlook's Add calendar page.

Open Add calendar page

3. Choose Subscribe from web.

4. Paste the link and finish adding it.

How it works

  • Important dates are selected from the official school calendar, Le Journal, and Le Bulletin.
  • They are added to a separate calendar you can subscribe to.
  • You add it once, then your calendar app keeps checking for updates.

If you want the complete official school calendar too, you can open that separately.

About this project

A parent-made helper

This is not an official school service. It is a parent-run calendar that combines important dates from the official school calendar, Le Journal, and Le Bulletin.

I made it because I kept missing dates in the emails, and the official calendar was often too noisy to use as a quick planning view.

If a date looks wrong or you use a different calendar app, please let me know.
